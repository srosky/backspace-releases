Private by design

Backspace keeps numbers, never keystrokes. No account, no analytics, no cloud. Your history lives in a small file on your Mac.

It counts. It doesn't read.

To notice a backspace in any app, macOS asks you to allow Input Monitoring. Here's exactly what Backspace does with it.

  • Stores only a tally per key type per day, never letters, words, timing or which app you were in.
  • Password fields are hidden from it by macOS, so they're never counted at all.
  • Listen-only: it can't change, block or send any key press.
  • The only network request is a daily check for app updates.
  • Signed by Northerly Labs Ltd. and notarized by Apple.

Up and counting in a minute.

Requires macOS 14 Sonoma or later, on Apple silicon or Intel.

  1. Download and install

    Open Backspace.zip and drag Backspace into your Applications folder, so updates can install themselves.

  2. Allow Input Monitoring

    Open Backspace and click Grant Access. In System Settings ▸ Privacy & Security ▸ Input Monitoring, switch on Backspace.

  3. That's it

    ⌫ 0 appears in your menu bar and starts counting. Click it for your stats, or open Settings to set a reset time or a daily limit.

Questions

Why does it need Input Monitoring?

It's the only way for an app to notice a key press while you're typing in another app. Backspace uses it in listen-only mode and keeps nothing but counts. You can switch it off any time in System Settings ▸ Privacy & Security ▸ Input Monitoring.

Does holding the key down count?

Yes. Each repeated delete counts, so the number matches the characters you actually removed. Per-press sounds stay quiet while the key repeats, unless you turn that off.

What happens if my Mac is asleep at reset time?

Backspace resets as soon as your Mac wakes up, and earlier presses stay with the day they belong to. Missed days don't show up as empty rows.

How do updates work?

Backspace checks once a day and offers new versions with a standard update window. You can turn automatic checks off in Settings ▸ General, or check by hand.

How do I uninstall it?

Quit Backspace from its menu bar window and move the app to the Trash. To remove your history too, delete ~/Library/Application Support/Backspace.
