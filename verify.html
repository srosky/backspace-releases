Don't take our word for it.

To notice a backspace in other apps, Backspace needs macOS's Input Monitoring permission. That permission is all-or-nothing: macOS can't limit it to one key. So instead of asking you to trust us, here are five checks you can run yourself in about five minutes.

These apply to Backspace 0.2.0 and later. Check your version in Backspace ▸ Settings ▸ About.

1It can't reach the internet

Backspace runs in the macOS App Sandbox, and the sandbox only allows what the app's signed entitlements list. Backspace has no network entitlement, so macOS itself blocks it from opening any connection, whatever its code tries to do. You can read the entitlements in Terminal:

codesign -d --entitlements - /Applications/Backspace.app

You should see exactly this:

[Dict]
	[Key] com.apple.security.app-sandbox
	[Value]
		[Bool] true
	[Key] com.apple.security.files.user-selected.read-only
	[Value]
		[Bool] true
	[Key] com.apple.security.temporary-exception.mach-lookup.global-name
	[Value]
		[Array]
			[String] com.simonroscoe.Backspace-spks
			[String] com.simonroscoe.Backspace-spki
EntitlementWhat it allows
app-sandboxTurns the sandbox on. Without an entitlement, the app can't do it.
files.user-selected.read-onlyRead a file you pick in an Open dialog: the custom sound option in Settings ▸ Feedback.
mach-lookup … -spks / -spkiTalk to Sparkle's installer helpers, so updates can be installed. Not network access.

What's missing is the point. There's no com.apple.security.network.client or network.server, and no access to your files beyond the one you pick.

How do updates work, then?

Update checks run in a separate, open-source helper from the Sparkle update framework. It has its own sandbox that allows network access and nothing else, and it only fetches the update feed and update files from GitHub. You can check its entitlements too:

codesign -d --entitlements - /Applications/Backspace.app/Contents/Frameworks/Sparkle.framework/Versions/B/XPCServices/Downloader.xpc
# expected: com.apple.security.app-sandbox  true
#            com.apple.security.network.client  true

If you'd rather have no network activity at all, turn off Settings ▸ General ▸ Check for updates automatically.

2Watch the network

For a live view, install a free network monitor such as LuLu (open source, by Objective-See). It asks before any app connects anywhere. With Backspace running, you should see:

  • Backspace: never.
  • Downloader (Sparkle): about once a day, to github.com and release-assets.githubusercontent.com, only while automatic update checks are on.

You can block the Downloader in LuLu if you like. Backspace keeps counting either way.

3Read everything it stores

All of Backspace's data is one small, human-readable file. Open it with Settings ▸ About ▸ Show Data File in Finder, or in Terminal:

open -e ~/Library/Containers/com.simonroscoe.Backspace/Data/Library/Application\ Support/Backspace/history.json

A day looks like this. Numbers per key type and a total keystroke count, nothing else:

{
  "label" : "2026-11-15",
  "start" : "2026-11-15T05:00:00Z",
  "end" : "2026-11-16T05:00:00Z",
  "manualResetCount" : 0,
  "tally" : {
    "counts" : { "backspace" : 226, "wordBackspace" : 9 },
    "keystrokes" : 2735
  }
}

No letters, words, timings or app names, because Backspace never keeps them. Settings are in ~/Library/Containers/com.simonroscoe.Backspace/Data/Library/Preferences/. Because the app is sandboxed, it can't write anywhere else.

4Check who made it

spctl --assess --type execute -vv /Applications/Backspace.app
/Applications/Backspace.app: accepted
source=Notarized Developer ID
origin=Developer ID Application: Northerly Labs Ltd. (Q2BFTP582X)

This shows the app is signed by Northerly Labs Ltd. and hasn't been changed since. To be clear about what this doesn't mean: Apple's notarization is an automated malware and signing check, not a privacy review. Checks 1–3 are the privacy evidence.

5Switch it off any time

  • Stop counting: System Settings ▸ Privacy & Security ▸ Input Monitoring ▸ turn off Backspace. It stops seeing key presses immediately.
  • Remove it completely: quit Backspace, move it to the Trash, and delete ~/Library/Containers/com.simonroscoe.Backspace.

Privacy policy

Last updated 15 November 2026. Applies to Backspace for macOS, published by Northerly Labs Ltd.

  • We collect no personal data. Backspace has no accounts, analytics, crash reporting or advertising.
  • On your Mac: Backspace stores daily counts per key type and a total keystroke count, as described above. It never stores or sends what you type. The data stays on your Mac and is deleted with the app's folder.
  • Update checks: if automatic checks are on, Sparkle's helper downloads the update feed from GitHub about once a day. Like any web request, GitHub receives your IP address and a user agent naming the app and its version. GitHub's handling of that is covered by the GitHub Privacy Statement. We don't receive or keep it.
  • Notifications are created locally on your Mac and contain only counts.
  • Questions: open an issue on GitHub.
